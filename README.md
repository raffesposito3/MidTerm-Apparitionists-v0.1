🔦 The Apparitionists
-------------------------------------------------------------------------------------------------------------------------------------------------
Where certainty is a trap.
-------------------------------------------------------------------------------------------------------------------------------------------------
The Apparitionists is a next-generation paranormal investigation simulator built to redefine the ghost-hunting genre. 
In an era where the supernatural has become predictable, this project strips away the comfort of reliable technology to 
return players to a state of true atmospheric dread."Tools are translators, not amplifiers." > We believe that a meter 
hitting a number isn't gameplay—interpretation is. In The Apparitionists, success is found in the gaps between the data.
-------------------------------------------------------------------------------------------------------------------------------------------------
🛠 Project Vision
-------------------------------------------------------------------------------------------------------------------------------------------------
This project moves away from binary evidence-gathering. Our goal is to create a living simulation where the environment 
and the entities within it react with nuance, deception, and intelligence.Uncertainty as a Core Mechanic: Equipment is prone 
to environmental interference, soul-draining malfunctions, and intentional entity manipulation.High-Skill Deduction: Evidence 
is never just a "check-box." Players must learn to recognize behavioral profiles, environmental cues, and historical tragedies
to truly understand what they are facing.Atmospheric Realism: Every location—from crumbling estates to forgotten graveyards—is 
designed as a character in its own right, facilitating interactions that don't require a tool to feel.
